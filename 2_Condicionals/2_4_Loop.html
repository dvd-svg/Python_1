Bucles simples

Objectius d'aprenentatge

  • Sabràs què significa un bucle en programació
  • Seràs capaç d'utilitzar un while True en els teus programes
  • Aprendràs a utilitzar la comanda break per sortir d'un bucle

Ja hem cobert les estructures condicionals amb cert detall. Una altra tècnica central en programació és la repetició, o iteració. Aquestes juntes formen les estructures de control fonamentals que tot programador ha de dominar. Es diuen estructures de control perquè permeten controlar quines línies de codi s'executen i quan. Mentre les estructures condicionals permeten escollir entre seccions de codi, les estructures d'iteració permeten repetir seccions de codi. Sovint s'anomenen bucles perquè permeten al programa "tornar enrere" a una línia que ja s'ha executat abans. L'execució d'una repetició d'un bucle també s'anomena iteració del bucle.

Aquesta secció introdueix un bucle while senzill. La seva estructura és similar a les sentències condicionals que ja hem vist. A la següent part aprofundirem en exemples més sofisticats.

Exemple de bucle senzill

Vegem un programa que demana a l'usuari que introdueixi un número i després imprimeix el quadrat del número. Això continua fins que l'usuari introdueix -1.

while True:
    numero = int(input("Introdueix un número, -1 per sortir: "))

    if numero == -1:
        break

    print(numero ** 2)

print("Gràcies i adéu!")

Executant el programa podria semblar així:

Introdueix un número, -1 per sortir: 2
4
Introdueix un número, -1 per sortir: 4
16
Introdueix un número, -1 per sortir: 10
100
Introdueix un número, -1 per sortir: -1
Gràcies i adéu!

Com es pot veure, el programa demana diversos números gràcies a la instrucció while. Quan l'usuari escriu -1, s'executa la comanda break, que surt del bucle i continua l'execució des de la primera línia després del bloc while.

Bucle infinit

Amb els bucles, és crucial que sempre hi hagi una manera de sortir del bucle en algun moment, si no la repetició podria continuar indefinidament. Per il·lustrar-ho, modifiquem una mica l'exemple anterior:

numero = int(input("Introdueix un número, -1 per sortir: "))
while True:
    if numero == -1:
        break

    print(numero ** 2)

print("Gràcies i adéu!")

En aquesta versió, el programa demana a l'usuari un número fora del bucle. Si l'usuari introdueix qualsevol altre número que no sigui -1, el bucle mai no s'acaba, creant un bucle infinit:

Introdueix un número, -1 per sortir: 2
4
4
4
4
4
4
4
4
(continua indefinidament...)

Exemple amb PIN

El següent programa permet a l'usuari continuar només si introdueix el PIN correcte 1234:

while True:
    codi = input("Introdueix el teu PIN: ")
    if codi == "1234":
        break
    print("Incorrecte... torna-ho a provar")

print("PIN correcte!")

Exemple d'execució:

Introdueix el teu PIN: 0000
Incorrecte... torna-ho a provar
Introdueix el teu PIN: 9999
Incorrecte... torna-ho a provar
Introdueix el teu PIN: 1234
PIN correcte!

Bucles i variables auxiliars

Fem l'exemple de comprovació de PIN una mica més realista. Aquesta versió dóna a l'usuari només tres intents per introduir el PIN.

El programa utilitza dues variables auxiliars. La variable intents fa un seguiment del nombre de vegades que l'usuari ha escrit un PIN. La variable exit s'estableix a True o False segons si l'usuari aconsegueix iniciar sessió correctament.

intents = 0

while True:
    codi = input("Introdueix el teu PIN: ")
    intents += 1

    if codi == "1234":
        exit = True
        break

    if intents == 3:
        exit = False
        break

    # això s'imprimeix si el codi és incorrecte I encara queden intents
    print("Incorrecte... torna-ho a provar")

if exit:
    print("PIN correcte!")
else:
    print("Massa intents...")

Exemple d'execució amb èxit abans dels tres intents:

Introdueix el teu PIN: 0000
Incorrecte... torna-ho a provar
Introdueix el teu PIN: 1234
PIN correcte!

Exemple d'execució amb tres intents fallits:

Introdueix el teu PIN: 0000
Incorrecte... torna-ho a provar
Introdueix el teu PIN: 9999
Incorrecte... torna-ho a provar
Introdueix el teu PIN: 4321
Massa intents...

El bucle s'interromp quan l'usuari introdueix el PIN correcte o quan s'arriben a tres intents. La sentència if després del bucle comprova el valor de la variable exit i imprimeix un missatge adequat.

Depuració amb sentències print dins de bucles

Afegir bucles als programes també afegeix possibles fonts d'errors. És important dominar l'ús de sentències de depuració com vam veure a la primera secció d'aquesta part.

Vegem un programa gairebé idèntic a l'exemple anterior, però amb una diferència crucial:

intents = 0

while True:
    codi = input("Introdueix el teu PIN: ")
    intents += 1

    if intents == 3:
        exit = False
        break

    if codi == "1234":
        exit = True
        break

    print("Incorrecte... torna-ho a provar")

if exit:
    print("PIN correcte!")
else:
    print("Massa intents...")

Aquesta versió actua de manera inesperada quan l'usuari introdueix el PIN correcte en el tercer intent:

Introdueix el teu PIN: 0000
Incorrecte... torna-ho a provar
Introdueix el teu PIN: 9999
Incorrecte... torna-ho a provar
Introdueix el teu PIN: 1234
Massa intents...

Per trobar la causa, podem afegir prints estratègics dins del bucle:

while True:
    print("inici del bloc while:")
    codi = input("Introdueix el teu PIN: ")
    intents += 1

    print("intents:", intents)
    print("condicio1:", intents == 3)
    if intents == 3:
        exit = False
        break

    print("codi:", codi)
    print("condicio2:", codi == "1234")
    if codi == "1234":
        exit = True
        break

    print("Incorrecte... torna-ho a provar")

Sortida d'exemple amb aquests prints de depuració:

inici del bloc while:
Introdueix el teu PIN: 2233
intents: 1
condicio1: False
codi: 2233
condicio2: False
Incorrecte... torna-ho a provar
inici del bloc while:
Introdueix el teu PIN: 4545
intents: 2
condicio1: False
codi: 4545
condicio2: False
Incorrecte... torna-ho a provar
inici del bloc while:
Introdueix el teu PIN: 1234
intents: 3
condicio1: True
Massa intents...

Observem que en la tercera iteració, la condició del primer if és True i el bucle s'interromp abans d'arribar al segon if que comprova si el codi és correcte.

L'ordre de les condicions dins del bucle és una causa comuna d'errors. Les sentències print de depuració són sovint la manera més senzilla de detectar aquest tipus de problemes.

while True:
    # ...

    # aquest bloc s'executa massa aviat
    if intents == 3:
        exit = False
        break

    # la tercera iteració mai arriba a aquesta línia
    if codi == "1234":
        exit = True
        break

L'ordre de les sentències condicionals o de les diferents branques dins d'una condició és una causa comuna d'errors, especialment dins de bucles. Les sentències de depuració amb print sovint són la manera més senzilla de descobrir per què es produeix un error.

Exercici 6: Proper any de traspàs

Escriu un programa que demani un any i imprimeixi el següent any de traspàs.

Any: 2023
El proper any de traspàs després de 2023 és 2024

Si l'usuari introdueix un any que ja és de traspàs:

Any: 2024
El proper any de traspàs després de 2024 és 2028

Concatenació de cadenes amb l'operador +

L'exemple anterior de comprovació de PIN utilitzava una variable auxiliar intents per fer un seguiment de quantes vegades l'usuari havia intentat introduir un codi:

intents = 0

while True:
    codi = input("Introdueix el teu PIN: ")
    intents += 1
    # ...

La variable es defineix a zero fora del bucle, i cada iteració incrementa el seu valor en una unitat.

Una idea similar d'incrementació funciona amb variables de tipus cadena de text també. El programa podria, per exemple, fer un seguiment de tots els codis PIN que l'usuari ha escrit:

codis = ""
intents = 0

while True:
    codi = input("Introdueix el teu PIN: ")
    intents += 1
    codis += codi + ", "
    # ...

La variable auxiliar s'inicialitza com una cadena buida, és a dir, una cadena sense caràcters:

codis = ""

A cada iteració, la cadena es fa més llarga, ja que s'afegeix el codi que l'usuari ha introduït, juntament amb una coma:

codi = input("Introdueix el teu PIN: ")
codis += codi + ", "

Si l'usuari introdueix els codis 1111, 2222 i 1234, al final de l'execució del programa el valor de codis seria:

1111, 2222, 1234,

Conceptes clau

  • Bucle: Permet repetir un bloc de codi diverses vegades.
  • Iteració: Cada execució individual d'un bucle.
  • while True: Bucle que continua indefinidament fins que es troba un break.
  • break: Comanda que finalitza immediatament un bucle.
  • Variable auxiliar: Variable usada per controlar l'execució d'un bucle o registrar informació com intents o èxit.
