Combinació de condicions

Objectius d'aprenentatge

  • Saber utilitzar els operadors and, or i not en condicions.
  • Ser capaç d’escriure condicionals niats.

Operadors lògics

Pots combinar condicions amb els operadors lògics and i or. L’operador and especifica que totes les condicions donades han de ser certes al mateix temps. L’operador or indica que almenys una de les condicions ha de ser certa.

Per exemple, la condició nombre >= 5 and nombre <= 8 determina que nombre ha de ser com a mínim 5 i com a màxim 8, és a dir, ha d’estar entre 5 i 8.

nombre = int(input("Introdueix un nombre: "))
if nombre >= 5 and nombre <= 8:
    print("El nombre està entre 5 i 8")

Mentrestant, la condició nombre < 5 or nombre > 8 determina que el nombre ha de ser menor que 5 o major que 8. És a dir, no ha d’estar dins del rang de 5 a 8.

nombre = int(input("Introdueix un nombre: "))
if nombre < 5 or nombre > 8:
    print("El nombre no està dins del rang de 5 a 8")

La següent taula de veritat mostra el comportament d’aquests operadors en diferents situacions:

a b a and b a or b
False False False False
True False False True
False True False True
True True True True

A vegades cal saber si alguna cosa no és certa. L’operador not nega una condició:

a not a
True False
False True

L’exemple anterior amb el rang exclòs de 5 a 8 també es podria programar així:

nombre = int(input("Introdueix un nombre: "))
if not (nombre >= 5 and nombre <= 8):
    print("El nombre no està dins del rang de 5 a 8")

En programació, els operadors lògics també s’anomenen sovint operadors booleans.

Condicions combinades simplificades

La condició x >= a and x <= b és una forma molt comuna de comprovar si un nombre x està dins del rang d’a a b. Una expressió amb aquesta estructura funciona de la mateixa manera en la majoria de llenguatges de programació.

Python permet una notació simplificada per combinar condicions: a <= x <= b aconsegueix el mateix resultat que la versió més llarga amb and. Aquesta forma més curta pot ser més familiar des de les matemàtiques, però no és molt utilitzada en Python, ja que pocs altres llenguatges de programació tenen aquesta abreviació.

Combinació i enllaç de condicions

El següent programa demana a l’usuari que introdueixi quatre nombres. Després calcula quin dels quatre és el més gran, amb l’ajuda d’algunes condicions:

n1 = int(input("Nombre 1: "))
n2 = int(input("Nombre 2: "))
n3 = int(input("Nombre 3: "))
n4 = int(input("Nombre 4: "))

if n1 > n2 and n1 > n3 and n1 > n4:
    mes_gran = n1
elif n2 > n3 and n2 > n4:
    mes_gran = n2
elif n3 > n4:
    mes_gran = n3
else:
    mes_gran = n4

print(f"{mes_gran} és el més gran dels nombres.")
Nombre 1: 2
Nombre 2: 4
Nombre 3: 1
Nombre 4: 1
4 és el més gran dels nombres.

En l’exemple anterior, la primera condició n1 > n2 and n1 > n3 and n1 > n4 només és certa si totes tres condicions dins d’ella són certes.

Condicionals niats

Les sentències condicionals també es poden niar dins d’altres sentències condicionals. Per exemple, el següent programa comprova si un nombre és positiu i després si és parell o senar:

nombre = int(input("Introdueix un nombre: "))

if nombre > 0:
    if nombre % 2 == 0:
        print("El nombre és parell")
    else:
        print("El nombre és senar")
else:
    print("El nombre és negatiu o zero")
Introdueix un nombre: 3
El nombre és senar
Introdueix un nombre: 18
El nombre és parell
Introdueix un nombre: -4
El nombre és negatiu o zero

Amb les condicions niades és crucial que les sagnies siguin correctes. Les sagnies determinen quines branques estan vinculades entre si. Una branca if i una branca else amb la mateixa quantitat d’espais pertanyen a la mateixa estructura condicional.

El mateix resultat sovint es pot aconseguir utilitzant condicions niades o bé condicions combinades amb operadors lògics. L’exemple següent és funcionalment equivalent a l’anterior:

nombre = int(input("Introdueix un nombre: "))

if nombre > 0 and nombre % 2 == 0:
    print("El nombre és parell")
elif nombre > 0 and nombre % 2 != 0:
    print("El nombre és senar")
else:
    print("El nombre és negatiu o zero")

Cap dels dos enfocaments és millor per se, però en diferents situacions un pot semblar més lògic que l’altre. En aquest exemple, la majoria de gent troba més intuïtiu l’ús de condicions niades.

Conceptes clau

  • Condició: expressió que pot ser certa o falsa.
  • if: estructura que executa un bloc de codi si la condició és certa.
  • else: part alternativa que s’executa si la condició no es compleix.
  • elif: permet comprovar més d’una condició.
  • and / or / not: operadors lògics per combinar o negar condicions.
  • if niat: condicions dins d’altres condicions.
