Objectius d'aprenentatge

  • Ampliar coneixements sobre arguments i paràmetres de funcions

Repàs de les funcions en Python

Les funcions es defineixen amb la paraula clau def:

def missatge():
    print("Aquest missatge ha estat portat per una funció")

Aquesta funció es pot cridar dins del teu programa així:

missatge()

El teu programa imprimirà:

Aquest missatge ha estat portat per una funció

Els paràmetres i arguments d'una funció

Una funció pot rebre un o més arguments. Quan la funció és cridada, aquests arguments s'assignen a variables definides dins de la funció. Aquestes variables s'anomenen paràmetres, i es llisten entre parèntesis després del nom de la funció.

En el següent codi, la funció saluda té un paràmetre, mentre que la funció suma en té dos.

def saluda(nom):
    print("Hola,", nom)

def suma(a, b):
    print("La suma dels arguments és", a + b)

saluda("Anna")
suma(2, 3)
Hola, Anna
La suma dels arguments és 5

Paràmetres vs arguments

La terminologia sobre dades passades a funcions pot ser confusa. Alguns textos utilitzen els termes formals i reals per parlar de paràmetres i arguments. La documentació oficial de Python només utilitza els termes argument i paràmetre, i seguirem aquesta convenció.

Quan s'executa la crida saluda("Anna"), el valor de l'argument "Anna" s'assigna al paràmetre nom. Això vol dir que, durant l'execució, nom = "Anna". Si cridem la funció amb un altre argument, el valor serà diferent.

Aquesta terminologia pot semblar sobrera, però en informàtica és important ser precís. Utilitzar una terminologia ben definida ajuda a evitar confusions.

Funcions dins d'altres funcions

Pots cridar una funció dins d'una altra. De fet, ja ho hem fet quan hem utilitzat print dins de les nostres pròpies funcions.

El valor de retorn d'una funció

Les funcions també poden retornar valors. Per exemple, la funció incorporada de Python input retorna una cadena de text que l'usuari ha escrit. El valor retornat per una funció es pot desar en una variable:

paraula = input("Escriu una paraula: ")

Quan volem obtenir un nombre enter introduït per l'usuari, cal convertir l'entrada a un enter. La funció que fem servir per això és int, i també retorna un valor:

nombre = int(input("Escriu un nombre enter: "))

La funció int pren la cadena de text retornada per input com a argument, i retorna un valor de tipus enter, si pot convertir la cadena en un número.

La instrucció return

Les funcions que definim nosaltres també poden retornar valors. Per fer-ho, cal utilitzar la instrucció return. Per exemple, la següent funció la_meva_suma retorna la suma dels seus paràmetres:

def la_meva_suma(a, b):
    return a + b

resultat = la_meva_suma(2, 3)

print("Suma:", resultat)
Suma: 5

Un altre exemple de valor de retorn és aquesta funció que demana el nom de l'usuari i retorna la cadena de text que l'usuari escriu:

def demana_nom():
    nom = input("Com et dius? ")
    return nom

nom = demana_nom()
print("Hola,", nom)
Com et dius? Anna
Hola, Anna

La instrucció return fa que l'execució de la funció s'aturi immediatament. El següent és un mètode útil per crear una funció de comparació:

def mes_petit(a, b):
    if a < b:
        return a
    return b

print(mes_petit(3, 7))
print(mes_petit(5, 2))

La idea és que si a és més petit que b, la funció retorna a i surt immediatament. Si no, continua a la línia següent i retorna b. Una funció mai pot executar dues instruccions return en una sola crida.

3
2

També pots utilitzar return encara que la funció no retorni cap valor. En aquest cas, serveix per aturar l'execució de la funció:

def saluda(nom):
    if nom == "":
        print("???")
        return
    print("Hola,", nom)

saluda("Emilia")
saluda("")
saluda("Marc")

Si l'argument (que s'emmagatzema a la variable nom) és una cadena buida, la funció imprimeix ??? i surt.

Hola, Emilia
???
Hola, Marc

Ús dels valors retornats per funcions

Ja sabem que els valors de retorn d'una funció es poden desar en variables:

def la_meva_suma(a, b):
    return a + b

resultat = la_meva_suma(4, 6)
print("La suma és", resultat)
La suma és 10

El valor retornat per una funció és un valor com qualsevol altre. No cal desar-lo en una variable per utilitzar-lo com a argument d'una altra funció:

print("La suma és", la_meva_suma(4, 6))

El valor retornat per una funció pot ser també l'argument d'una altra funció:

def la_meva_suma(a, b):
    return a + b

def diferencia(a, b):
    return a - b

resultat = diferencia(la_meva_suma(5, 2), la_meva_suma(2, 3))
print("El resultat és", resultat)
El resultat és 2

En aquest cas, primer s'executen les crides internes la_meva_suma(5, 2) i la_meva_suma(2, 3). Els valors retornats (7 i 5) s'utilitzen com a arguments de la funció externa diferencia(7, 5), que retorna el valor 2. Aquest es desa a la variable resultat i s'imprimeix.

En resum, els valors retornats per funcions funcionen exactament igual que qualsevol altre valor a Python. Es poden imprimir, desar en variables, utilitzar en expressions i fer-los servir com a arguments en altres crides.

La diferència entre return i print

De vegades la diferència entre que una funció retorni un valor i que tingui una instrucció print pot ser confusa. Vegem dues maneres diferents d'implementar una funció que calcula quin dels dos valors és més gran:

def maxim1(a, b):
    if a > b:
        return a
    else:
        return b

def maxim2(a, b):
    if a > b:
        print(a)
    else:
        print(b)

resultat = maxim1(3, 5)
print(resultat)

maxim2(7, 2)
5
7

Ambdues versions semblen funcionar correctament, ja que imprimeixen el valor màxim. No obstant això, hi ha una diferència fonamental entre elles. La primera, maxim1, no imprimeix res per si sola, sinó que retorna el valor més gran. Si executem la línia següent:

maxim1(3, 5)

no sembla que passi res, ja que el valor retornat s'ha d'utilitzar d'alguna manera, per exemple, desant-lo en una variable i imprimint-lo:

resultat = maxim1(3, 5)
print(resultat)

La segona versió, maxim2, utilitza print dins la funció per mostrar el valor més gran. Si volem veure el valor, n'hi ha prou amb cridar la funció:

maxim2(7, 5)

El desavantatge d'aquesta funció és que el valor calculat no queda disponible per ser utilitzat més endavant en el programa. Per això, les funcions que retornen valors acostumen a ser l'opció més recomanable.

El tipus dels arguments

Un petit repàs dels tipus de dades que hem vist fins ara:

Tipus Tipus de dada en Python Exemple
enter int 23
número decimal float -0.45
cadena de text str "Peter Python"
valor booleà bool True

Quan cridem una funció, només funcionarà correctament si els arguments que li passem són del tipus adequat. Vegem un exemple:

def imprimeix_varios_cops(missatge, cops):
    while cops > 0:
        print(missatge)
        cops -= 1

La funció funciona com s'espera si la cridem així:

imprimeix_varios_cops("Hola a tothom", 5)
Hola a tothom
Hola a tothom
Hola a tothom
Hola a tothom
Hola a tothom

Tanmateix, si li passem un argument del tipus incorrecte, la funció no funcionarà:

imprimeix_varios_cops("Hola a tothom", "Emily")
TypeError: '>' not supported between instances of 'str' and 'int'

El problema aquí és que el segon paràmetre, cops, es compara amb un enter (0) a la línia 2 de la definició de la funció. L'argument passat és "Emily", que és una cadena de text (str), no un enter (int). Les cadenes i els enters no es poden comparar tan fàcilment, i per això es produeix un error.

Per evitar problemes com aquest, podem afegir anotacions de tipus a la definició de la funció. Les anotacions indiquen quin tipus d'argument s'espera:

def imprimeix_varios_cops(missatge: str, cops: int):
    while cops > 0:
        print(missatge)
        cops -= 1

Això indica a qui faci servir la funció que missatge hauria de ser una cadena de text i cops hauria de ser un enter.

De la mateixa manera, també podem indicar quin tipus de valor retorna una funció:

def demana_nom() -> str:
    nom = input("Com et dius? ")
    return nom

Això indica que la funció hauria de retornar una cadena de text.

Nota: Les anotacions de tipus només són pistes sobre el tipus dels arguments o del valor retornat. No són una garantia ni una protecció contra errors de tipus. Si una funció rep o retorna un valor del tipus incorrecte, s'executarà igualment, però pot no funcionar correctament.

Conceptes clau

  • Return: instrucció que retorna un valor d'una funció
  • Valor de retorn: resultat que una funció torna al ser cridada
  • Diferència return vs print: return torna un valor, print mostra per pantalla
  • Anotacions de tipus: indicar el tipus esperat dels paràmetres i retorn
  • Reutilització de funcions: usar funcions existents per construir noves
  • Abstracció: ocultar detalls complexos darrere d'interfícies simples
  • Descomposició de problemes: dividir problemes complexos en parts més petites
