Llegir fitxers CSV

CSV és un format tan simple que fins ara hem accedit amb codi escrit a mà. Hi ha, però, un mòdul predefinit a la biblioteca estàndard de Python per treballar amb fitxers CSV: csv. Funciona així:

import csv

with open("test.csv") as fitxer:
    for linia in csv.reader(fitxer, delimiter=";"):
        print(linia)

El codi anterior llegeix totes les línies del fitxer CSV test.csv, separa els continguts de cada línia en una llista utilitzant el delimitador ;, i imprimeix cada llista. Així, suposant que els continguts de la línia són els següents:

012121212;5
012345678;2
015151515;4

El codi imprimiria això:

['012121212', '5']
['012345678', '2']
['015151515', '4']

Com que el format CSV és tan simple, quina utilitat té tenir un mòdul separat quan podem utilitzar igualment la funció split? Doncs, per començar, la manera com està construït el mòdul, també funcionarà correctament si els valors al fitxer són cadenes de text, que també poden contenir el caràcter delimitador. Si alguna línia del fitxer tingués aquest aspecte:

"aaa;bbb";"ccc;ddd"

el codi anterior produiria això:

['aaa;bbb', 'ccc;ddd']

Utilitzar la funció split també dividiria dins de les cadenes, cosa que probablement trencaria les dades i el nostre programa en el procés.

Llegir fitxers JSON

CSV és només un dels molts formats de dades llegibles per màquina. JSON és un altre, i s'utilitza sovint quan les dades s'han de transferir entre aplicacions.

Els fitxers JSON són fitxers de text amb un format estricte, que és potser una mica menys accessible a la vista humana que el format CSV. L'exemple següent utilitza el fitxer courses.json, que conté informació sobre alguns cursos:

[
    {
        "name": "Introduction to Programming",
        "abbreviation": "ItP",
        "periods": [1, 3]
    },
    {
        "name": "Advanced Course in Programming",
        "abbreviation": "ACiP",
        "periods": [2, 4]
    },
    {
        "name": "Database Application",
        "abbreviation": "DbApp",
        "periods": [1, 2, 3, 4]
    }
]

L'estructura d'un fitxer JSON et pot resultar bastant familiar ara. El fitxer JSON anterior s'assembla exactament a una llista de Python, que conté tres diccionaris de Python.

La biblioteca estàndard té un mòdul per treballar amb fitxers JSON: json. La funció loads pren qualsevol argument passat en format JSON i el transforma en una estructura de dades de Python. Així, processar el fitxer courses.json amb el codi següent:

import json

with open("courses.json") as fitxer:
    dades = fitxer.read()

cursos = json.loads(dades)
print(cursos)

imprimiria el següent:

[{'name': 'Introduction to Programming', 'abbreviation': 'ItP', 'periods': [1, 3]}, {'name': 'Advanced Course in Programming', 'abbreviation': 'ACiP', 'periods': [2, 4]}, {'name': 'Database Application', 'abbreviation': 'DbApp', 'periods': [1, 2, 3, 4]}]

Si també volguéssim imprimir el nom de cada curs, podríem ampliar el nostre programa amb un bucle for:

for curs in cursos:
    print(curs["name"])
Introduction to Programming
Advanced Course in Programming
Database Application

Recuperar un fitxer d'internet

La biblioteca estàndard de Python també conté mòduls per tractar continguts en línia, i una funció útil és urllib.request.urlopen. T'animem a fer una ullada a tot el mòdul, però l'exemple següent hauria de ser suficient perquè t'hi familiaritzis amb la funció. Es pot utilitzar per recuperar continguts d'internet, de manera que es puguin processar als teus programes.

El codi següent imprimiria els continguts de la pàgina principal de la Universitat de Helsinki:

import urllib.request

peticio = urllib.request.urlopen("https://helsinki.fi")
print(peticio.read())

Les pàgines destinades a la vista humana normalment no tenen un aspecte molt bonic quan el seu codi s'imprimeix. En els exemples següents, però, treballarem amb dades llegibles per màquina d'una font en línia. Moltes de les dades llegibles per màquina disponibles en línia estan en format JSON.

Recuperar la llista de cursos actius

A l'adreça https://studies.cs.helsinki.fi/stats-mock/api/courses trobaràs informació bàsica sobre alguns dels cursos oferts pel Departament d'Informàtica de la Universitat de Helsinki, en format JSON.

Escriu una funció anomenada retrieve_all(), que recupera les dades de tots els cursos que actualment estan actius (el camp enabled té el valor true). Aquests s'han de retornar com una llista de tuples, en el següent format:

[
    ('Full Stack Open 2020', 'ofs2019', 2020, 201),
    ('DevOps with Docker 2019', 'docker2019', 2019, 36),
    ('DevOps with Docker 2020', 'docker2020', 2020, 36),
    ('Beta DevOps with Kubernetes', 'beta-dwk-20', 2020, 28)
]

Cada tuple conté els següents camps de les dades originals:

  • el nom del curs: fullName
  • name
  • year
  • la suma dels valors llistats a exercises

Nota: És essencial que recuperis les dades amb la funció urllib.request.urlopen, o els tests automàtics podrien no funcionar correctament.

Nota 2: Els tests estan dissenyats perquè modifiquen lleugerament les dades recuperades d'internet, per assegurar-se que no codifiques de forma rígida els teus valors de retorn.

Nota 3: Alguns usuaris de Mac s'han trobat amb el següent problema:

Recuperar les dades per a un sol curs

Cada curs també té la seva pròpia URL, on hi ha dades setmanals més específiques sobre el curs disponible. Les URL segueixen el format https://studies.cs.helsinki.fi/stats-mock/api/courses/****/stats, on hauries de reemplaçar els asteriscs amb els continguts del camp name per al curs al qual vulguis accedir.

Per exemple, les dades per al curs docker2019 estan a l'adreça https://studies.cs.helsinki.fi/stats-mock/api/courses/docker2019/stats.

Escriu una funció anomenada retrieve_course(course_name: str), que retorna estadístiques per al curs especificat, en format diccionari.

Per exemple, la crida de funció retrieve_course("docker2019") retornaria un diccionari amb els següents continguts:

{
    'weeks': 4,
    'students': 220,
    'hours': 5966,
    'hours_average': 27,
    'exercises': 4988,
    'exercises_average': 22
}

Els valors al diccionari es determinen de la manera següent:

  • weeks: el nombre de literals d'objecte JSON recuperats
  • students: el nombre màxim d'estudiants en totes les setmanes
  • hours: la suma de tots els valors hour_total en les diferents setmanes
  • hours_average: el valor hours dividit pel valor students (arrodonit cap avall a l'enter més proper)
  • exercises: la suma de tots els valors exercise_total en les diferents setmanes
  • exercises_average: el valor exercises dividit pel valor students (arrodonit cap avall a l'enter més proper)

Nota 2: El mòdul math de Python té una funció útil per arrodonir enters cap avall.

Exercici: Qui va enganyar

El fitxer start_times.csv conté temps d'inici individuals per a un examen de programació, en el format nom;hh:mm. Un exemple:

jarmo;09:00
timo;18:42
kalle;13:23

A més, el fitxer submissions.csv conté punts i temps de lliurament per a exercicis individuals. El format aquí és nom;tasca;punts;hh:mm. Un exemple:

jarmo;1;8;16:05
timo;2;10;21:22
jarmo;2;10;19:15
etc...

La teva tasca és trobar els estudiants que van passar més de 3 hores en les tasques de l'examen. És a dir, qualsevol estudiant la qual tasca es va lliurar més de 3 hores després del seu temps d'inici de l'examen s'etiqueta com a enganyós. Pot haver-hi més d'una entrega per a la mateixa tasca per a cada estudiant. Pots assumir que totes les hores estan dins del mateix dia.

Escriu una funció anomenada cheaters(), que retorna una llista que conté els noms dels estudiants que van enganyar.

Exercici: Qui va enganyar, versió 2

Tens els fitxers CSV de l'exercici anterior a la teva disposició de nou. Escriu una funció anomenada final_points(), que retorna els punts finals de l'examen rebuts pels estudiants, en format diccionari, seguint aquests criteris:

  • Si hi ha múltiples entregues per a la mateixa tasca, es té en compte l'entrega amb el nombre més alt de punts.
  • Si l'entrega es va fer més de 3 hores després de l'hora d'inici, l'entrega s'ignora.
  • Les tasques estan numerades de l'1 al 8, i cada entrega es qualifica amb 0 a 6 punts.

Al diccionari retornat la clau ha de ser el nom de l'estudiant, i el valor els punts totals rebuts per l'estudiant.

Pista: els diccionaris niats podrien ser un bon enfocament quan es processen les tasques i els temps de lliurament de cada estudiant.

Exercici: Corrector ortogràfic, versió 2

En aquest exercici escriuràs una versió millorada del Corrector ortogràfic de la part anterior.

Igual que en la versió anterior, el programa ha de demanar a l'usuari que escrigui una línia de text. El teu programa ha de realitzar una comprovació ortogràfica i imprimir retroalimentació a l'usuari, de manera que totes les paraules mal escrites tinguin estels al voltant. A més, el programa ha d'imprimir una llista de suggeriments per a les paraules mal escrites.

Fes una ullada als dos exemples següents.

escriu text: We use ptython to make a spell checker

We use *ptython* to make a spell checker
suggestions:
ptython: python, pythons, typhon
escriu text: this is acually a good and usefull program

this is *acually* a good and *usefull* program
suggestions:
acually: actually, tactually, factually
usefull: usefully, useful, museful

Els suggeriments s'han de determinar amb la funció get_close_matches del mòdul difflib de la biblioteca estàndard de Python.

Nota: Perquè els tests automàtics funcionin correctament, si us plau utilitza la funció amb la "configuració per defecte". És a dir, si us plau passa només dos arguments a la funció: la paraula mal escrita, i la llista de paraules.
