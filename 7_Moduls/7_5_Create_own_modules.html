Crear els teus propis mòduls Python

Escriure els teus propis mòduls Python és fàcil. Qualsevol fitxer que contingui codi Python vàlid pot ser importat com a mòdul. Suposem que tenim un fitxer anomenat paraules.py amb el següent contingut:

def primera_paraula(meu_text: str):
    parts = meu_text.split(" ")
    return parts[0]

def darrera_paraula(meu_text: str):
    parts = meu_text.split(" ")
    return parts[-1]

def nombre_paraules(meu_text: str):
    parts = meu_text.split(" ")
    return len(parts)

Les funcions definides al fitxer poden ser accedides important el fitxer:

import paraules

meu_text = "La Sílvia ven conquilles a la costa"

print(paraules.primera_paraula(meu_text))
print(paraules.darrera_paraula(meu_text))
print(paraules.nombre_paraules(meu_text))

Nota: el fitxer que conté el mòdul Python ha d'estar ubicat o bé en el mateix directori que el programa que l'importa, o en un dels directoris per defecte de Python, o si no l'intèrpret de Python no el trobarà quan s'executi la sentència d'importació.

Podem utilitzar els nostres propis mòduls tal com hem après a utilitzar els mòduls de la biblioteca estàndard de Python:

from paraules import primera_paraula, darrera_paraula

frase = input("Escriu una frase: ")

print("La primera paraula era: " + primera_paraula(frase))
print("La darrera paraula era: " + darrera_paraula(frase))

Utilitzant les indicacions de tipus

Quan s'utilitzen mòduls, les indicacions de tipus esdevenen especialment útils. Si utilitzes un editor que té suport integrat per a les indicacions de tipus, l'ús de diferents mòduls es fa molt més fàcil.

Per exemple, Visual Studio Code mostrarà les indicacions de tipus quan estiguis escrivint codi.

Codi de la funció principal en un mòdul

Si un mòdul conté codi que no està dins d'una definició de funció (és a dir, si el mòdul conté codi en la funció principal del mòdul), aquest codi s'executa automàticament sempre que el mòdul s'importa.

Suposem que el nostre fitxer paraules.py també contenia alguns casos de prova:

def primera_paraula(meu_text: str):
    parts = meu_text.split(" ")
    return parts[0]

def darrera_paraula(meu_text: str):
    parts = meu_text.split(" ")
    return parts[-1]

def nombre_paraules(meu_text: str):
    parts = meu_text.split(" ")
    return len(parts)

print(primera_paraula("Això és una prova"))
print(darrera_paraula("Aquí encara estem provant"))
print(nombre_paraules("Un dos tres quatre cinc"))

Ara, si importem el mòdul amb una sentència d'importació, tot el codi del mòdul que està fora de les funcions definides s'executa automàticament:

import paraules

meu_text = "La Sílvia ven conquilles a la costa"

print(paraules.primera_paraula(meu_text))
print(paraules.darrera_paraula(meu_text))
print(paraules.nombre_paraules(meu_text))

Com podeu veure a dalt, això no és un bon resultat, perquè el programa que estem intentant escriure es veu alterat pels casos de prova del propi mòdul.

Per sort, hi ha una solució. Només hem de comprovar si el programa s'està executant per si mateix, o si el codi ha estat importat amb una sentència d'importació. Python té una variable incorporada __name__, que conté el nom del programa que s'està executant. Si el programa s'està executant per si mateix, el valor de la variable és __main__. Si el programa ha estat importat, el valor de la variable és el nom del mòdul importat (en aquest cas, paraules).

Sabent això, podem afegir una sentència condicional, que ens permet executar només els casos de prova si el programa s'executa per si mateix. Com podeu veure a sota, l'estructura us resulta familiar:

def primera_paraula(meu_text: str) -> str:
    parts = meu_text.split(" ")
    return parts[0]

def darrera_paraula(meu_text: str) -> str:
    parts = meu_text.split(" ")
    return parts[-1]

def nombre_paraules(meu_text: str) -> int:
    parts = meu_text.split(" ")
    return len(parts)

if __name__ == "__main__":
    # provant funcionalitat
    print(primera_paraula("Això és una prova"))
    print(darrera_paraula("Aquí encara estem provant"))
    print(nombre_paraules("Un dos tres quatre cinc"))

Si executeu el mòdul per si mateix, els casos de prova es mostren:

Quan el mòdul s'importa en un altre programa, els casos de prova no s'executen:

import paraules

meu_text = "La Sílvia ven conquilles a la costa"

Exercici 1: Ajudant de text

Escriu un mòdul anomenat ajudant_text, que contingui les següents funcions:

La funció canviar_majuscules(text_original: str) crea i retorna una nova versió del paràmetre text. Les lletres minúscules en l'original haurien de ser majúscules, i les lletres majúscules haurien de ser minúscules.

La funció dividir_meitat(text_original: str) divideix el paràmetre text per la meitat, i retorna els resultats en una tupla. Si l'original té un nombre senar de caràcters, la primera meitat hauria de ser més curta.

La funció eliminar_caracters_especials(text_original: str) retorna una nova versió del paràmetre text, amb tots els caràcters especials eliminats. Només es permeten lletres minúscules i majúscules, números i espais en el text retornat.

Alguns exemples de com s'utilitzaria el mòdul:

import ajudant_text

meu_text = "Hola, com estàs!"

print(ajudant_text.canviar_majuscules(meu_text))

p1, p2 = ajudant_text.dividir_meitat(meu_text)

print(p1)
print(p2)

m2 = ajudant_text.eliminar_caracters_especials("Això és una prova, vejam com va!!!11!")
print(m2)

Conceptes clau

  • Mòduls propis: crear fitxers Python reutilitzables per organitzar codi amb funcions i variables.
  • __name__ i __main__: variables especials per controlar l'execució del codi i diferenciar entre importació i execució directa.
