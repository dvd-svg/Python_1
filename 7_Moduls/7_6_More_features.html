Característiques útils de Python

Per acabar aquest curs, aquí trobareu diverses característiques útils de Python.

Condicionals d'una sola línia

Les dues sentències següents produeixen exactament els mateixos resultats:

if x%2 == 0:
    print("parell")
else:
    print("senar")
print("parell" if x%2 == 0 else "senar")

En l'últim exemple tenim una expressió condicional en una sola línia: a if [condició] else b. El valor d'aquesta expressió s'avalua com a a si la condició és certa, i com a b si és falsa. Aquesta estructura de vegades s'anomena operador ternari.

Les expressions condicionals poden ser molt útils quan necessites assignar alguna cosa condicionalment. Per exemple, si tens les variables x i y, i vols incrementar o establir el valor de y depenent de la paritat de x, podries escriure-ho en una sentència if else normal, així:

if x%2 == 0:
    y += 1
else:
    y = 0

El mateix es podria aconseguir amb una línia elegant:

y = y + 1 if x%2 == 0 else 0

Un bloc "buit"

Potser recordes de la part anterior que no es permet tenir un bloc buit en un programa de Python. Si necessites tenir un bloc de codi que no fa res, per exemple quan proves alguna altra funcionalitat, la comanda pass et permetrà fer això. Podries, per exemple, escriure una funció que no fa res:

def provant():
    pass

Aquesta funció simplement retornaria immediatament. Ometre la comanda pass, és a dir, tenir un bloc completament buit, produiria un error.

def provant():  # això causa un error!

Bucles amb blocs else

En Python, els bucles també poden tenir blocs else. Aquesta secció de codi s'executa si el bucle acaba normalment.

Per exemple, en l'exemple següent estem buscant a través d'una llista de nombres. Si hi ha un nombre parell a la llista, el programa imprimeix un missatge i el bucle es trenca. Si no hi ha nombres parells, el bucle acaba normalment, però llavors s'imprimeix un missatge diferent.

llista_meva = [3,5,2,8,1]
for x in llista_meva:
    if x%2 == 0:
        print("trobat un nombre parell", x)
        break
else:
    print("no hi havia nombres parells")

Una manera més tradicional d'aconseguir això seria utilitzar una variable auxiliar per recordar si s'ha trobat l'element desitjat:

llista_meva = [3,5,2,8,1]
trobat = False
for x in llista_meva:
    if x%2 == 0:
        print("trobat un nombre parell", x)
        trobat = True
        break
if not trobat:
    print("no hi havia nombres parells")

Utilitzar una sentència for else ens estalvia la molèstia d'escriure una variable separada.

Valor per defecte dels paràmetres

Una funció Python pot tenir un valor de paràmetre per defecte. S'utilitza quan no es passa cap argument a la funció. Vegeu l'exemple següent:

def digues_hola(nom="Anna"):
    print("Hola,", nom)

digues_hola()
digues_hola("Eduard")
digues_hola("Marta")
digues_hola("")
Hola, Anna
Hola, Eduard
Hola, Marta
Hola,

Nota: una cadena buida segueix sent una cadena, de manera que el paràmetre per defecte no s'utilitza si es passa una cadena buida a la funció.

Un nombre variable de paràmetres

També pots definir una funció amb un nombre variable de paràmetres, afegint un asterisc abans del nom del paràmetre. Tots els arguments restants passats a la funció es conten en una tupla, i es poden accedir a través del paràmetre amb nom.

La funció següent compta el nombre i la suma dels seus arguments:

def provant(*els_meus_args):
    print("Has passat", len(els_meus_args), "arguments")
    print("La suma dels arguments és", sum(els_meus_args))

provant(1, 2, 3, 4, 5)
Has passat 5 arguments
La suma dels arguments és 15

Exercici 1: El teu propi llenguatge de programació

En aquest exercici escriuràs el teu propi executor de llenguatge de programació. Pots utilitzar qualsevol tècnica i habilitat que hagis après en aquest curs fins ara.

Els programes consistiran en files, i cada fila estarà en un dels formats següents:

  • PRINT [valor]: imprimeix el valor
  • MOV [variable] [valor]: assigna el valor a la variable
  • ADD [variable] [valor]: afegeix el valor a la variable
  • SUB [variable] [valor]: resta el valor de la variable
  • MUL [variable] [valor]: multiplica la variable pel valor
  • [ubicació]::: anomena una línia de codi, per poder saltar-hi des d'un altre lloc
  • JUMP [ubicació]: salta a la ubicació especificada
  • IF [condició] JUMP [ubicació]: si la condició és certa, salta a la ubicació especificada
  • END: acaba l'execució

Els claudàtors anteriors són només una notació per significar operands; vegeu a continuació exemples d'ús.

El programa s'executa línia per línia des de la primera línia endavant. L'execució acaba quan l'executor es troba amb la comanda END, o quan no queden més línies per executar.

Cada programa té 26 variables predefinides, anomenades de la A a la Z. Cada variable té el valor 0 quan el programa comença. La notació [variable] es refereix a una d'aquestes 26 variables.

Tots els valors processats pel programa són nombres enters. La notació [valor] es refereix ja sigui a un valor emmagatzemat en una variable, o a un nombre enter escrit directament.

La notació [ubicació] es refereix a qualsevol nom d'una ubicació que consisteixi en lletres minúscules de la a a la z i/o nombres del 0 al 9. Dues ubicacions diferents no poden tenir el mateix nom.

La notació [condició] es refereix a qualsevol expressió en el format [valor] [comparació] [valor], on [comparació] és un dels operadors següents: ==, !=, <, <=, > i >=.

Si us plau, escriu una funció anomenada run(programa), que pren una llista que conté les comandes del programa com a argument. Cada element de la llista és una línia de codi en el programa. La funció ha de retornar una nova llista, que conté els resultats de les comandes PRINT executades durant l'execució del programa.

Pots assumir que la funció només rebrà programes que estan completament en el format correcte. No has d'implementar cap validació d'entrada o maneig d'errors.

A continuació hi ha alguns exemples, que també pots utilitzar per provar. Exemple 1:

programa1.append("MOV B 2")
programa1.append("PRINT A")
programa1.append("PRINT B")
programa1.append("ADD A B")
programa1.append("PRINT A")
programa1.append("END")
resultat = run(programa1)
print(resultat)
[1, 2, 3]

Conceptes clau

  • Expressió condicional (operador ternari): Permet escriure condicionals if-else en una sola línia amb la sintaxi a if condició else b.
  • Comanda pass: Utilitzada com a marcador de posició per a blocs de codi buits, evitant errors de sintaxi.
  • Blocs else en bucles: S'executen quan un bucle (for o while) acaba normalment, sense que es produeixi un break.
  • Valors per defecte en paràmetres de funcions: Permet definir valors preestablerts per als arguments d'una funció, que s'utilitzen si no se'n proporciona cap.
  • Nombre variable de paràmetres (*args): Permet que una funció accepti un nombre arbitràri d'arguments, emmagatzemats en una tupla.
