Tuples

Objectius d'aprenentatge

  • Familiaritzar-se amb el tipus de dades tuple
  • Ser capaç de crear tuples a partir de diversos tipus de valors
  • Conèixer la diferència entre una tuple i una llista
  • Poder nomenar alguns usos típics per a les tuples

Les tuples

Una tuple és una estructura de dades que, en molts aspectes, és similar a una llista. Les diferències més importants entre les dues són:

Les tuples s'encapsulen entre (), mentre que les llistes s'encapsulen entre []

Les tuples són immutables, mentre que el contingut d'una llista pot canviar

El següent fragment de codi crea una tuple que conté les coordenades d'un punt:

punt = (10, 20)

Accedir als elements d'una tupla

Els elements emmagatzemats en una tuple s'accedeixen per índex, igual que els elements emmagatzemats en una llista:

punt = (10, 20)
print("coordenada x:", punt[0])
print("coordenada y:", punt[1])
coordenada x: 10
coordenada y: 20

Immutabilitat de les tuples

Els valors emmagatzemats en una tuple no es poden canviar després que la tuple ha estat definida. El següent no funcionarà:

punt = (10, 20)
punt[0] = 15
TypeError: 'tuple' object does not support item assignment

El primer element de la tuple és el més petit dels arguments

Exercici: La persona més vella

Escriu una funció anomenada persona_mes_vella(persones: llista), que rep una llista de tuples com a argument. En cada tuple, el primer element és el nom d'una persona, i el segon element és el seu any de naixement. La funció ha de trobar la persona més vella de la llista i retornar el seu nom.

Quin és el propòsit d'una tupla?

Les tuples són ideals quan hi ha un conjunt de valors que estan connectats d'alguna manera. Per exemple, quan cal gestionar les coordenades x i y d'un punt, una tuple és una elecció natural, perquè les coordenades sempre consistiran en dos valors:

punt = (10, 20)

Tècnicament, és possible també utilitzar una llista per emmagatzemar-ho:

punt = [10, 20]

Una llista és una col·lecció d'elements consecutius en un ordre determinat. La mida d'una llista també pot canviar. Quan emmagatzemem les coordenades d'un punt, volem emmagatzemar específicament les coordenades x i y, no una llista arbitrària que contingui aquests valors.

Tuples com a claus en diccionaris

Com que les tuples són immutables, a diferència de les llistes, es poden utilitzar com a claus en un diccionari. El següent fragment de codi crea un diccionari, on les claus són punts de coordenades:

punts = {}
punts[(3, 5)] = "mico"
punts[(5, 0)] = "plàtan"
punts[(1, 2)] = "clavicèmbal"
print(punts[(3, 5)])
mico

Intentar una definició similar de diccionari utilitzant llistes no funcionaria:

punts = {}
punts[[3, 5]] = "mico"
punts[[5, 0]] = "plàtan"
punts[[1, 2]] = "clavicèmbal"
print(punts[[3, 5]])
TypeError: unhashable type: 'list'

Tuples sense parèntesis

Els parèntesis no són estrictament necessaris quan es defineixen tuples. Les dues assignacions de variables següents són idèntiques en els seus resultats:

nombres = (1, 2, 3)
nombres = 1, 2, 3

Això vol dir que també podem retornar fàcilment múltiples valors utilitzant tuples. Vegem l'exemple següent:

def minmax(llista):
  return min(llista), max(llista)

llista = [33, 5, 21, 7, 88, 312, 5]

valor_min, valor_max = minmax(llista)
print(f"L'element més petit és {valor_min} i l'element més gran és {valor_max}")
L'element més petit és 5 i l'element més gran és 312

Aquesta funció retorna dos valors en una tuple. El valor de retorn s'assigna a dues variables alhora:

valor_min, valor_max = minmax(llista)

Utilitzar parèntesis pot fer que la notació sigui més clara. A la part esquerra de la sentència d'assignació també tenim una tuple, que conté dos noms de variables. Els valors continguts dins la tuple retornada per la funció s'assignen a aquestes dues variables.

(valor_min, valor_max) = minmax(llista)

Tuples amb el mètode items

Potser recordes el mètode de diccionari items en la secció anterior. El vam utilitzar per accedir a totes les claus i valors emmagatzemats en un diccionari:

diccionari = {}

diccionari["mico"] = "monkey"
diccionari["plàtan"] = "banana"
diccionari["clavicèmbal"] = "harpsichord"

for clau, valor in diccionari.items():
    print("clau:", clau)
    print("valor:", valor)

Les tuples també treballen aquí. El mètode diccionari.items() retorna cada parell clau-valor com una tuple, on el primer element és la clau i el segon element és el valor.

Intercanviar valors amb tuples

Un altre ús comú per a les tuples és intercanviar els valors de dues variables:

nombre1, nombre2 = nombre2, nombre1

La sentència d'assignació anterior intercanvia els valors emmagatzemats en les variables nombre1 i nombre2. El resultat és idèntic al que s'aconsegueix amb el següent fragment de codi, utilitzant una variable auxiliar:

auxiliar = nombre1
nombre1 = nombre2
nombre2 = auxiliar

Exercici: Base de dades d'estudiants

Part 1: Afegir estudiants

Primer escriu una funció anomenada afegir_estudiant, que afegeix un nou estudiant a la base de dades. També escriu una versió preliminar de la funció imprimir_estudiant, que imprimeix la informació d'un sol estudiant.

Aquestes funcions s'utilitzen així:

estudiants = {}
afegir_estudiant(estudiants, "Pere")
afegir_estudiant(estudiants, "Elisabet")
imprimir_estudiant(estudiants, "Pere")
imprimir_estudiant(estudiants, "Elisabet")
imprimir_estudiant(estudiants, "Joan")

El teu programa ara hauria d'imprimir:

Pere:
 cap curs completat
Elisabet:
 cap curs completat
Joan: no hi ha aquesta persona a la base de dades

Part 2: Afegir cursos completats

Escriu una funció anomenada afegir_curs, que afegeix un curs completat a la informació d'un estudiant específic a la base de dades. Les dades del curs són una tuple que consisteix en el nom del curs i la nota:

estudiants = {}
afegir_estudiant(estudiants, "Pere")
afegir_curs(estudiants, "Pere", ("Introducció a la Programació", 3))
afegir_curs(estudiants, "Pere", ("Curs Avançat de Programació", 2))
imprimir_estudiant(estudiants, "Pere")

Quan s'han afegit alguns cursos, la informació impresa canvia:

 2 cursos completats:
  Introducció a la Programació 3
  Curs Avançat de Programació 2
 nota mitjana 2.5

Part 3: Repetir cursos

Els cursos amb nota 0 s'han d'ignorar quan s'afegeix informació del curs. Addicionalment, si el curs ja està a la base de dades en la informació d'aquest estudiant específic, la nota registrada a la base de dades mai ha de baixar si el curs es repeteix.

afegir_estudiant(estudiants, "Pere")
afegir_curs(estudiants, "Pere", ("Introducció a la Programació", 3))
afegir_curs(estudiants, "Pere", ("Curs Avançat de Programació", 2))
afegir_curs(estudiants, "Pere", ("Estructures de Dades i Algorismes", 0))
afegir_curs(estudiants, "Pere", ("Introducció a la Programació", 2))
imprimir_estudiant(estudiants, "Pere")
Pere:
 2 cursos completats:
  Introducció a la Programació 3
  Curs Avançat de Programació 2
 nota mitjana 2.5

Part 4: Resum de la base de dades

Escriu una funció anomenada resum, que imprimeix un resum basat en tota la informació emmagatzemada a la base de dades.

estudiants = {}
afegir_estudiant(estudiants, "Pere")

Conceptes clau

  • Tuple: estructura de dades immutable similar a una llista.
  • Parèntesis: s'utilitzen per definir tuples ().
  • Tuples sense parèntesis: la definició sense parèntesis és vàlida i equivalent.
  • Retorn múltiple: les tuples permeten retornar diversos valors des d'una funció.
  • Desempaquetament: assignació de valors de tuple a múltiples variables.
  • Intercanvi de valors: tècnica elegant per intercanviar variables amb tuples.
  • Col·leccions relacionades: ús ideal per agrupar valors conceptualment units.
