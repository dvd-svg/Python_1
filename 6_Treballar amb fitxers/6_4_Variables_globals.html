Variables locals i globals

Objectius d'aprenentatge

  • Entendre que s'enten per variable local
  • Comprendre com l'àmbit d'una variable afecta el seu ús
  • Utilitzar la paraula clau global de Python
  • Aplicar variables locals i globals en els contextos correctes

L'abast de les variables

L'abast d'una variable es refereix a les parts d'un programa on una variable és accessible. Una variable local només és accessible en una part definida del programa, mentre que una variable global està disponible per a ús en qualsevol part del programa.

Variables locals

Les variables definides dins d'una funció de Python són variables locals, només disponibles dins de la funció. Això s'aplica tant als paràmetres de la funció com a altres variables definides dins de la definició de la funció. Una variable que és local a una funció no existeix fora de la funció.

En l'exemple següent intentem accedir a la variable x a la funció principal, però això provoca un error:

def prova():
    x = 5
    print(x)

prova()
print(x)
5
NameError: name 'x' is not defined

La variable x només existeix mentre s'està executant la funció prova. Altres funcions o la funció principal no poden accedir a la variable.

Variables globals

Les variables definides dins de la funció principal són variables globals. Anteriorment vam definir la funció principal com aquelles parts de codi en un programa de Python que no es troben dins de cap altra funció. El valor emmagatzemat en una variable global es pot accedir des de qualsevol altra funció del programa, de manera que el següent no provoca cap error:

def prova():
    print(x)

x = 3
prova()
3

Una variable global no es pot canviar directament des d'una altra funció. La següent funció no té cap efecte sobre el valor emmagatzemat a la variable global:

def prova():
    x = 5
    print(x)

x = 3
prova()
print(x)
5
3

Aquí la funció prova crea una nova variable local x, que "emmascara" la variable global mentre s'està executant la funció. Aquesta variable té el valor 5, però és una variable diferent de la global x que està definida a la funció principal.

La paraula clau global

Si volem especificar que volem canviar la variable global dins d'una funció, necessitarem la paraula clau de Python global:

def prova():
    global x
    x = 3
    print(x)

x = 5
prova()
print(x)
3
3

Ara l'assignació x = 3 dins de la funció també afecta la funció principal. Totes les parts del programa estan utilitzant la mateixa variable global x.

Quan s'han d'utilitzar variables globals?

Les variables globals no són una manera d'evitar els paràmetres de les funcions o els valors de retorn, i no s'han d'utilitzar com a tal. És a dir, és possible escriure una funció que emmagatzemi els seus resultats directament en una variable global:

def calcula_suma(a, b):
    global resultat
    resultat = a + b

calcula_suma(2, 3)
print(resultat)

És millor escriure una funció amb un valor de retorn, com estem acostumats a fer:

def calcula_suma(a, b):
    return a + b

resultat = calcula_suma(2, 3)
print(resultat)

L'avantatge d'aquest darrer enfocament és que la funció és un tot independent. Té uns paràmetres definits i retorna un resultat. No té efectes secundaris, de manera que es pot provar i canviar independentment de les altres parts del programa.

Les variables globals són útils en situacions on necessitem tenir alguna informació comuna, de "nivell superior" disponible per a totes les funcions del programa. El següent és un exemple d'aquest tipus de situació:

def calcula_suma(a, b):
    global comptador
    comptador += 1
    return a + b

def calcula_diferencia(a, b):
    global comptador
    comptador += 1
    return a - b


comptador = 0
print(calcula_suma(2, 3))
print(calcula_suma(5, 5))
print(calcula_diferencia(5, 2))
print(calcula_suma(1, 0))
print("Hi va haver", comptador, "crides a funcions")
5
10
3
1
Hi ha hagut 4 crides a funcions

En aquest cas volem fer un seguiment de quantes vegades s'han cridat les funcions durant l'execució del programa. La variable global comptador és útil aquí, perquè podem incrementar-la des de les pròpies funcions mentre s'executen, però encara accedir al valor final a la funció principal.

Passar dades d'una funció a una altra, revisitat

Si un programa consta de múltiples funcions, sovint sorgeix la qüestió de passar dades d'una funció a una altra.

Quan vam tocar aquest tema anteriorment, teníem un programa que demana a l'usuari alguns valors enters, els imprimeix i realitza algun anàlisi estadístic sobre els números. El programa es dividia en tres funcions separades:

def entrada_usuari(quants: int):
    print(f"Si us plau, introdueix {quants} números:")
    numeros = []

    for i in range(quants):
        numero = int(input(f"Número {i+1}: "))
        numeros.append(numero)

    return numeros

def imprimeix_resultat(numeros: list):
    print("Els números són: ")
    for numero in numeros:
        print(numero)

def analitza(numeros: list):
    mitjana = sum(numeros) / len(numeros)
    return f"Hi ha {len(numeros)} números en total, la mitjana és {mitjana}, el més petit és {min(numeros)} i el més gran és {max(numeros)}"

# la funció principal que utilitza aquestes funcions
entrades = entrada_usuari(5)
imprimeix_resultat(entrades)
resultat_analisi = analitza(entrades)
print(resultat_analisi)

Un exemple de l'execució del programa:

Si us plau, introdueix 5 números:
Número 1: 10
Número 2: 34
Número 3: -32
Número 4: 99
Número 5: -53
Els números són:
10
34
-32
99
-53
Hi ha 5 números en total, la mitjana és 11.6, el més petit és -53 i el més gran és 99

El principi bàsic aquí és que la funció principal "emmagatzema" les dades processades pel programa. Aquí, això significa els números introduïts per l'usuari, que s'emmagatzemen a la variable entrades.

Si els números es necessiten en alguna funció, la variable es passa com a argument, com es veu anteriorment quan es criden les funcions imprimeix_resultat i analitza. Si la funció produeix un resultat que és rellevant en altres parts del programa, la funció retorna això amb una sentència return, com es veu amb les funcions entrada_usuari i analitza anteriorment.

Com sempre en programació, hi ha moltes maneres d'arribar a la mateixa funcionalitat. Seria possible utilitzar la paraula clau global i fer que les funcions accedeixin directament a la variable entrades definida a la funció principal. Hi ha bones raons per les quals això no és una jugada intel·ligent, però. Quan moltes funcions diferents poden accedir i potencialment alterar una variable directament, es torna difícil fer un seguiment fiable de l'estat del programa, el que pot fer que el programa sigui impredictible. Això és especialment cert a mesura que augmenta el nombre de funcions involucrades, cosa que és comuna en grans projectes de programari.

En conclusió, passar dades cap a i des de les funcions es gestiona millor mitjançant arguments i valors de retorn.

Funció principal explícita

També podries separar la funció principal implícita en l'exemple anterior en la seva pròpia funció principal explícita. Llavors la variable entrades ja no seria una variable global, sinó una variable local dins de la funció principal:

# la teva funció principal va aquí
def main():
    entrades = entrada_usuari(5)
    imprimeix_resultat(entrades)
    resultat_analisi = analitza(entrades)

    print(resultat_analisi)

# executa la funció principal
main()

Conceptes clau

  • Abast d'una variable: parts del programa on una variable és accessible.
  • Variable local: accessible només dins de la funció on es defineix.
  • Variable global: accessible des de qualsevol part del programa.
  • Paraula clau global: permet modificar una variable global des d'una funció.
  • Passar dades entre funcions: mitjançant arguments i valors de retorn, no amb variables globals.
  • Funció principal (main): on es coordina l'execució del programa i es gestionen les dades globals com a variables locals de la funció principal.
