Condicionals

Objectius d'aprenentatge

  • Aprendre a utilitzar un condicional simple en programació.
  • Comprendre què és un valor booleà.
  • Expressar condicions utilitzant operadors de comparació.

Fins ara, cada programa que hem escrit s'ha executat línia per línia en ordre. Sovint és útil crear seccions del programa que només s'executin en determinades situacions.

Per exemple, el següent codi comprova si l'usuari és major d'edat:

edat = int(input("Quants anys tens? "))

if edat > 17:
    print("Ets major d'edat!")
    print("Aquí tens una còpia del GTA6 per a tu.")

print("Següent client, si us plau!")

Si l'usuari té més de 17 anys, el programa mostrarà:

Quants anys tens? 18
Ets major d'edat!
Aquí tens una còpia del GTA6 per a tu.
Següent client, si us plau!

Si l'usuari té 17 anys o menys, només es mostrarà:

Quants anys tens? 16
Següent client, si us plau!

Aquests exemples ens mostren que el valor introduït determina quines parts del programa s'executen. El programa conté una sentència condicional amb un bloc de codi que només s'executa si la condició és certa.

Estructura d'un if

En una sentència condicional, la paraula clau if va seguida d'una condició, com una comparació de dos valors. El bloc de codi que segueix només s'executa si la condició és certa.

Cal posar dos punts després de la capçalera if. Si s'ometen, es produeix un error:

edat = 10

# sense dos punts al final de la línia següent
if edat > 17
    print("Ets major d'edat.")
File "programa.py", line 3
  if edat > 17
            ^
SyntaxError: sintaxi invàlida

Operadors de comparació

Sovint les condicions comparen dos valors. A continuació es mostren els operadors més comuns:

  • ==: Igual a (a == b)
  • !=: Diferent de (a != b)
  • >: Major que (a > b)
  • >=: Major o igual que (a >= b)
  • <: Menor que (a < b)
  • <=: Menor o igual que (a <= b)

Exemple d'un programa que mostra missatges diferents segons si un nombre és positiu, negatiu o zero:

numero = int(input("Introdueix un nombre: "))

if numero < 0:
    print("El nombre és negatiu.")

if numero > 0:
    print("El nombre és positiu.")

if numero == 0:
    print("El nombre és zero.")

Sortides esperades amb diferents entrades:

Introdueix un nombre: 15
El nombre és positiu.
Introdueix un nombre: -18
El nombre és negatiu.
Introdueix un nombre: 0
El nombre és zero.

Indentació

Python reconeix que un bloc de codi forma part d'una condicional si cada línia del bloc té la mateixa indentació. Cada línia ha de començar amb la mateixa quantitat d'espais.

contrasenya = input("Introdueix una contrasenya: ")

if contrasenya == "gatet":
    print("Coneixies la contrasenya!")
    print("Has de ser l'usuari previst...")
    print("...o un hacker molt hàbil.")

print("El programa ha finalitzat. Gràcies i adéu!")

Pots utilitzar la tecla Tab per afegir espais o l'editor sovint farà la indentació automàtica després dels dos punts.

Valors booleans i expressions booleanes

Qualsevol condició dins d'una sentència condicional produeix un valor de veritat, és a dir, True o False. Per exemple, a < 5 és True si a és menor que 5 i False si és igual o més gran.

Aquests valors es diuen booleans i en Python es gestionen amb el tipus bool. Les variables bool només poden tenir True o False, sempre els escriurem amb la primera lletra en majúscula.

Qualsevol codi que generi un valor booleà és una expressió booleana. Per exemple, la condició dins d'una sentència condicional és sempre una expressió booleana.

a = 3
condicio = a < 5
print(condicio)
if condicio:
    print("a és menor que 5")
True
a és menor que 5

Les paraules clau de Python True i False també es poden utilitzar directament. En l'exemple següent, l'ordre print() s'executa cada vegada, perquè el valor de la condició és True:

condicio = True
if condicio:
    print("Això es mostra sempre.")
Això es mostra sempre.

Un programa com aquest no és gaire útil, però més endavant durant el curs veureu exemples de variables booleanes que resultaran molt pràctiques.

Exercici 10: Resolució d'equació quadràtica

En el mòdul math de Python hi ha la funció sqrt que permet calcular l'arrel quadrada d'un nombre, la podem utilitzar així:

from math import sqrt

print(sqrt(9))
3.0

Tornarem al concepte de mòdul i la sentència import més endavant. Per ara, n'hi ha prou amb entendre que la línia from math import sqrt ens permet utilitzar la funció sqrt al nostre programa. Escriu un programa per resoldre una equació de segon grau de la forma ax²+bx+c. El programa demana els valors a, b i c. Després hauria d'utilitzar la fórmula quadràtica per resoldre l'equació.

La fórmula quadràtica expressada amb la funció sqrt de Python és la següent: x = (-b ± sqrt(b²-4ac))/(2a). Pots assumir que l'equació sempre tindrà dues arrels reals, de manera que la fórmula anterior sempre funcionarà. Un exemple de com hauria de funcionar és:

Valor de a: 1
Valor de b: 2
Valor de c: -8

Les arrels són 2.0 i -4.0

Conceptes clau

  • Sentència condicional: Executa un bloc de codi només si la condició és certa.
  • Condició: Expressió que retorna un valor booleà (True o False).
  • Operadors de comparació: ==, !=, >, >=, <, <=, s'utilitzen per comparar valors.
  • Indentació: Espais al principi de cada línia per indicar blocs de codi dins d'una condició.
  • Valor booleà: Representa la veritat d'una condició, True o False.
  • Expressió booleana: Qualsevol codi que produeix un valor booleà.
