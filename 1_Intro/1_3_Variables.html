Més sobre les variables

Objectius d'aprenentatge

  • Fer servir variables en diferents contextos.
  • Conèixer quin tipus de dades es pot guardar en una variable.
  • Entendre la diferència entre cadenes de text, enters i nombres amb decimals.

Variables en programació

Les variables són necessàries per a diversos propòsits en programació. Pots utilitzar variables per emmagatzemar qualsevol informació que es necessitarà més tard en l'execució del programa.

En programació Python les variables es creen així:

nom_variable = ...

Aquí ... significa el valor emmagatzemat a la variable.

Per exemple, quan vas utilitzar la comanda input per llegir una cadena de text de l'usuari, vas emmagatzemar la cadena en una variable i després vas utilitzar la variable més tard al teu programa:

nom = input("Com et dius? ")
print("Hola, " + nom)
Com et dius? Fantasmin
Hola, Fantasmin

El valor emmagatzemat en una variable també es pot definir utilitzant altres variables:

nom_propi = "Pau"
cognom = "Python"

nom = nom_propi + " " + cognom

print(nom)
Pau Python

Aquí els valors emmagatzemats en les tres variables no s'obtenen de l'entrada de l'usuari. Romanen iguals cada vegada que s'executa el programa. Això es diu codificar dades de forma fixa al programa.

Canviar el valor d'una variable

Com el nom variable implica, el valor emmagatzemat en una variable pot canviar. A la secció anterior vam notar que el nou valor reemplaça l'anterior.

Durant l'execució del programa següent, la variable paraula tindrà tres valors diferents:

paraula = input("Si us plau, escriu una paraula: ")
print(paraula)

paraula = input("I una altra paraula: ")
print(paraula)

paraula = "tercera"
print(paraula)
Si us plau, escriu una paraula: primera
primera
I una altra paraula: segona
segona
tercera

El valor emmagatzemat a la variable canvia cada vegada que s'assigna un nou valor a la variable.

El nou valor d'una variable es pot derivar del seu valor anterior. A l'exemple següent la variable paraula primer s'assigna un valor basat en l'entrada de l'usuari. Després se li assigna un nou valor, que és el valor anterior amb tres signes d'exclamació afegits al final.

paraula = input("Si us plau, escriu una paraula: ")
print(paraula)

paraula = paraula + "!!!"
print(paraula)
Si us plau, escriu una paraula: prova
prova
prova!!!

Escollir un bon nom per a una variable

Sovint és útil anomenar les variables d'acord amb allò per a què s'utilitzen. Per exemple, si la variable conté una paraula, el nom paraula és una millor opció que, diguem, a.

No hi ha un límit establert per a la longitud d'un nom de variable a Python, però hi ha algunes altres limitacions. Un nom de variable ha de començar amb una lletra, i només pot contenir lletres, números i guions baixos _.

Les lletres minúscules i majúscules són caràcters diferents. Les variables nom, Nom i NOM són totes variables diferents. Mentre que aquesta regla té algunes excepcions, les ignorarem per ara.

Una pràctica de programació comuna a Python consisteix en utilitzar només caràcters en minúscula en els noms de variables. Si el nom de variable consisteix en múltiples paraules, utilitza un guió baix entre les paraules. Mentre que aquesta regla també té algunes excepcions, les ignorarem per ara.

Enters

Fins ara, només hem emmagatzemat cadenes de text en variables, però també hi ha molts altres tipus d'informació que voldrem emmagatzemar i accedir més tard. Anem a fer una ullada als enters primer. Els enters són números que no tenen una part decimal o fraccional, com -15, 0 i 1.

El programa següent crea la variable edat, que conté un valor enter.

edat = 24
print(edat)

El programa imprimeix només això:

24

Nota la manca de cometes aquí. De fet, si afegíssim cometes al voltant del número, això significaria que la nostra variable ja no seria un enter, sinó una cadena de text. Una cadena de text pot contenir números, però es processa de manera diferent.

Aleshores, per què importa que les variables tinguin un tipus, quan el programa següent encara imprimeix el mateix dues vegades?

numero1 = 100
numero2 = "100"

print(numero1)
print(numero2)
100
100

Els tipus de variables importen perquè diferents operacions afecten diferents tipus de variables de maneres diferents. Anem a fer una ullada a un exemple:

numero1 = 100
numero2 = "100"

print(numero1 + numero1)
print(numero2 + numero2)

Això imprimeix el següent:

200
100100

Per a valors enters l'operador + significa addició, però per a valors de cadena significa concatenació, o "enganxar junts".

No tots els operadors estan disponibles per a tots els tipus de variables. Mentre que els números es poden dividir utilitzant l'operador de divisió /, intentar dividir una cadena per un número causa un error:

numero = "100"
print(numero / 2)
TypeError: unsupported operand type(s) for /: 'str' and 'int'

Combinar valors quan s'imprimeix

Similarment, el programa següent no funcionarà, perquè "El resultat és " i resultat són de dos tipus diferents:

resultat = 10 * 25
# la línia següent produeix un error
print("El resultat és " + resultat)

El programa no imprimeix res, sinó que llança un error:

TypeError: unsupported operand type(s) for +: 'str' and 'int'

Aquí, Python ens diu que combinar dos tipus diferents de valors no funcionarà així com així. En aquest cas, "El resultat és " és de tipus cadena, mentre que el valor emmagatzemat a resultat és de tipus enter.

Si volem imprimir una cadena i un enter en una sola comanda, l'enter es pot convertir a cadena amb la funció str, i després les dues cadenes es poden combinar normalment. Per exemple, això funcionaria:

resultat = 10 * 25
print("El resultat és " + str(resultat))
El resultat és 250

La comanda print també té funcionalitats incorporades que suporten combinar diferents tipus de valors. La manera més simple és afegir una coma entre els valors. Tots els valors s'imprimiran independentment del seu tipus:

resultat = 10 * 25
print("El resultat és", resultat)
El resultat és 250

Nota que hi ha un caràcter d'espai en blanc afegit automàticament entre els valors separats per una coma aquí.

Imprimir amb cadenes-f

Què passa si volem tenir més flexibilitat i control sobre el que imprimim? Les anomenades cadenes-f són una altra manera de formatar sortides impreses a Python. La sintaxi inicialment pot semblar una mica confusa, però al final les cadenes-f són sovint la manera més simple de formatar text.

Amb cadenes-f l'exemple anterior es veuria així:

resultat = 10 * 25
print(f"El resultat és {resultat}")

Anem a desglossar això. Al principi de la cadena que estem imprimint hi ha el caràcter f. Això li diu a Python que el que segueix és una cadena-f. Dins de la cadena, tancat en claus, hi ha el nom de la variable resultat. El valor que conté es converteix en una part de la cadena impresa. La sortida impresa és exactament la mateixa que en els exemples anteriors:

El resultat és 250

Una sola cadena-f pot contenir múltiples variables. Per exemple aquest codi

nom = "Marc"
edat = 37
ciutat = "Palo Alto"
print(f"Hola {nom}, tens {edat} anys. Vius a {ciutat}.")

imprimeix això:

Hola Marc, tens 37 anys. Vius a Palo Alto.

És difícil crear una sortida impresa exactament com aquesta utilitzant la notació de coma en la comanda print. Per exemple, aquest programa

nom = "Marc"
edat = 37
ciutat = "Palo Alto"
print("Hola", nom, ", tens", edat, "anys. Vius a", ciutat, ".")

imprimeix el següent:

Hola Marc , tens 37 anys. Vius a Palo Alto .

Nota l'espai en blanc inserit automàticament entre cada part separada per coma de la sortida impresa. Impedir que print afegeixi els espais extra és tècnicament possible, però no val la pena donat que podem utilitzar cadenes-f en lloc d'això.

En la seva simplicitat la notació de coma de la comanda print sovint pot ser útil, però a vegades causa més problemes del que val. Les cadenes-f són generalment una opció més fiable. A la part 4 aprendràs més sobre les característiques pràctiques de les cadenes-f quan es tracta de formatar sortides impreses.

Exercici 1: Espai extra

La teva amiga està treballant en una aplicació per a buscadors de feina. T'envia aquest tros de codi:

nom = "Tim Tester"
edat = 20
habilitat1 = "python"
nivell1 = "principiant"
habilitat2 = "java"
nivell2 = "veterà"
habilitat3 = "programació"
nivell3 = "semiprofessional"
minim = 2000
maxim = 3000

print("my name is ", nom, " , I am ", edat, "years old")
print("my skills are")
print("- ", habilitat1, " (", nivell1, ")")
print("- ", habilitat2, " (", nivell2, ")")
print("- ", habilitat3, " (", nivell3, " )")
print("I am looking for a job with a salary of", minim, "-", maxim, "euros per month")

El programa hauria d'imprimir exactament el següent:

my name is Tim Tester, I am 20 years old

my skills are
 - python (beginner)
 - java (veteran)
 - programming (semiprofessional)

I am looking for a job with a salary of 2000-3000 euros per month

El codi funciona gairebé correctament, però no del tot. Aquest exercici té proves molt estrictes, que comproven la sortida per a cada bit d'espai en blanc.

Arregla el codi perquè la sortida impresa es vegi correcta. Nota especialment com la notació de coma en la comanda print insereix automàticament un espai al voltant de les diferents parts separades per coma.

La manera més fàcil de transformar el codi perquè compleixi els requisits és utilitzar cadenes-f.

Pista: pots imprimir una línia buida afegint una comanda print buida, o afegint el caràcter de nova línia \n a la teva cadena.

Recorda anar molt acurat quan formategis sortides impreses també en el futur en aquest curs. Alguns dels exercicis tenen proves que requereixen que la teva sortida sigui exactament com s'especifica en els exemples donats. Utilitza caràcters d'espai en blanc reals en el teu codi, en lloc de codis de caràcter ASCII per a espai en blanc, o alguna cosa així.

Nombres de punt flotant

Nombre de punt flotant o float és un terme que trobaràs sovint en programació. Es refereix a nombres amb un punt decimal. Es poden utilitzar de manera similar als valors enters.

Aquest programa calcula la mitjana de tres nombres de punt flotant:

numero1 = 2.5
numero2 = -1.25
numero3 = 3.62

mitjana = (numero1 + numero2 + numero3) / 3
print(f"Mitjana: {mitjana}")
Mitjana: 1.6233333333333333

Exercici 2: Aritmètica

Aquest programa ja conté dues variables enteres, x i y:

x = 27
y = 15

Completa el programa perquè també imprimeixi el següent:

27 + 15 = 42
27 - 15 = 12
27 * 15 = 405
27 / 15 = 1.8

El programa hauria de funcionar correctament fins i tot si es canvien els valors de les variables. És a dir, si les dues primeres línies es reemplacen amb això

x = 4
y = 9

el programa hauria d'imprimir el següent:

4 + 9 = 13
4 - 9 = -5
4 * 9 = 36

Exercici 3: Arregla el codi: Imprimeix una sola línia

Cada comanda print normalment imprimeix una línia pròpia, completa amb un canvi de línia al final. No obstant això, si a la comanda print se li dóna un argument addicional end = "", no imprimirà un canvi de línia.

Per exemple:

print("Hola ", end="")
print("allà!")
Hola allà!

Arregla aquest programa perquè tot el càlcul, complet amb el resultat, s'imprimeixi en una sola línia. No canviïs el nombre de comandes print utilitzades.

print(5)
print(" + ")
print(8)
print(" - ")
print(4)
print(" = ")
print(5 + 8 - 4)

Conceptes clau

  • Variable: espai on es desa informació per utilitzar-la més endavant.
  • Tipus de dades: defineix el tipus d'informació (cadena, enter, decimal...).
  • Enter: nombre sense part decimal.
  • Float: nombre amb part decimal.
  • Concatenació: unir dues o més cadenes de text.
  • f-string: cadena de text especial que permet incrustar variables dins del text.
  • str(): converteix un valor a cadena de text.
