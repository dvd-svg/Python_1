Més sobre les variables

Objectius d’aprenentatge

  • Fer servir variables en diferents contextos.
  • Conèixer quin tipus de dades es poden guardar en una variable.
  • Entendre la diferència entre cadenes de text, enters i nombres amb decimals.

Les variables són essencials en programació. Serveixen per guardar informació que necessitarem més endavant durant l’execució d’un programa.

En Python, una variable es crea així:

nom_variable = ...

On ... representa el valor que es vol desar dins la variable.

Crear i utilitzar variables

Per exemple, quan fem servir la comanda input per llegir una cadena de text introduïda per l’usuari, podem guardar aquest valor en una variable i fer-lo servir després:

nom = input("Com et dius? ")
print("Hola, " + nom)
Com et dius? Pau
Hola, Pau

També podem definir el valor d’una variable fent servir altres variables:

nom_propi = "Pau"
cognom = "Python"

nom_complet = nom_propi + " " + cognom

print(nom_complet)
Pau Python

Això s’anomena codificar dades fixes (hard-coding), ja que no provenen de l’usuari sinó que estan definides dins del codi.

Canviar el valor d’una variable

Tal com indica el seu nom, una variable pot canviar de valor. En aquest exemple, el valor de la variable paraula canvia tres vegades:

paraula = input("Escriu una paraula: ")
print(paraula)

paraula = input("I una altra paraula: ")
print(paraula)

paraula = "tercera"
print(paraula)
Escriu una paraula: primera
primera
I una altra paraula: segona
segona
tercera

El valor d’una variable també pot derivar-se del valor anterior:

paraula = input("Escriu una paraula: ")
print(paraula)

paraula = paraula + "!!!"
print(paraula)
Escriu una paraula: prova
prova
prova!!!

Escollir un bon nom per a una variable

És recomanable donar noms descriptius a les variables segons el seu ús. Per exemple, si la variable conté una paraula, és millor paraula que a.

Els noms de variable han de començar amb una lletra i només poden contenir lletres, números i guions baixos _.

Python distingeix entre majúscules i minúscules: nom, Nom i NOM són tres variables diferents.

Per convenció, a Python s’utilitzen només minúscules i es separen les paraules amb guions baixos: data_naixement, nom_complet, etc.

Variables amb nombres enters

Fins ara hem desat cadenes de text, però també podem desar nombres. Els enters són nombres sense part decimal, com ara -15, 0 o 1.

edat = 24
print(edat)
24

Si posem cometes al voltant del número, ja no serà un enter sinó una cadena de text. Tot i que sembli igual, Python el tracta de manera diferent.

Tipus de dades i operacions

Els tipus de dades són importants perquè les operacions es comporten de manera diferent segons el tipus. Observa aquest exemple:

num1 = 100
num2 = "100"

print(num1 + num1)
print(num2 + num2)
200
100100

Amb nombres, + fa una suma; amb cadenes, fa una concatenació.

No totes les operacions serveixen per a tots els tipus. Aquest codi dona un error:

numero = "100"
print(numero / 2)
TypeError: unsupported operand type(s) for /: 'str' and 'int'

Combinar valors en la sortida

El següent programa no funciona perquè intenta sumar una cadena i un enter:

resultat = 10 * 25
print("El resultat és " + resultat)
TypeError: unsupported operand type(s) for +: 'str' and 'int'

Per combinar tipus diferents, podem convertir l’enter a text amb str():

resultat = 10 * 25
print("El resultat és " + str(resultat))
El resultat és 250

També podem separar els valors amb comes dins de print:

resultat = 10 * 25
print("El resultat és", resultat)
El resultat és 250

Imprimir amb f-strings

Una altra manera molt pràctica és utilitzar f-strings:

resultat = 10 * 25
print(f"El resultat és {resultat}")
El resultat és 250

Podem incloure múltiples variables en una sola f-string:

nom = "Marta"
edat = 37
ciutat = "Barcelona"
print(f"Hola {nom}, tens {edat} anys i vius a {ciutat}.")
Hola Marta, tens 37 anys i vius a Barcelona.

Amb f-strings és més fàcil evitar espais de més i controlar exactament com surt el text.

Exercici: Espais addicionals

El teu amic està treballant en una aplicació per a persones que busquen feina i t’ha enviat aquest fragment de codi:

nom = "Toni Tester"
edat = 20
habilitat1 = "python"
nivell1 = "principiant"
habilitat2 = "java"
nivell2 = "expert"
habilitat3 = "programació"
nivell3 = "semiprofessional"
inferior = 2000
superior = 3000

print("el meu nom és ", nom, " , tinc ", edat, " anys")
print("les meves habilitats són")
print("- ", habilitat1, " (", nivell1, ")")
print("- ", habilitat2, " (", nivell2, ")")
print("- ", habilitat3, " (", nivell3, " )")
print("busco una feina amb un sou de", inferior, "-", superior, "euros al mes")

El programa hauria d’imprimir exactament el següent:

el meu nom és Toni Tester, tinc 20 anys

les meves habilitats són
 - python (principiant)
 - java (expert)
 - programació (semiprofessional)

busco una feina amb un sou de 2000-3000 euros al mes

Corregeix el codi perquè la sortida sigui correcta. Fixa’t especialment en com la notació amb comes dins del comandament print afegeix automàticament un espai al voltant de les diferents parts separades per comes.

La manera més senzilla de transformar el codi perquè compleixi els requisits és utilitzar f-strings.

Pista: pots imprimir una línia buida afegint un comandament print() buit, o afegint el caràcter de nova línia \n dins de la teva cadena de text.

Recorda ser especialment atent amb el format de les sortides també en futurs exercicis.

Nombres amb decimals (float)

Els nombres amb decimals (o float) representen nombres amb punt decimal. Es poden utilitzar de manera similar als enters.

num1 = 2.5
num2 = -1.25
num3 = 3.62

mitjana = (num1 + num2 + num3) / 3
print(f"Mitjana: {mitjana}")
Mitjana: 1.6233333333333333

Exercici: Operacions aritmètiques

Aquest programa ja conté dues variables de tipus enter, x i y:

x = 27
y = 15

Completa el programa perquè també imprimeixi el resultat de les següents operacions aritmètiques:

27 + 15 = 42
27 - 15 = 12
27 * 15 = 405
27 / 15 = 1.8

El programa ha de funcionar correctament encara que els valors de les variables es modifiquin. Per exemple, si les primeres dues línies es substitueixen per:

x = 4
y = 9

El programa hauria d’imprimir el següent:

4 + 9 = 13
4 - 9 = -5
4 * 9 = 36
4 / 9 = 0.4444444444444444

Exercici: Imprimir tot en una sola línia

Cada comandament print normalment imprimeix una línia completa amb un salt de línia al final. No obstant això, si s’afegeix l’argument end="", no s’afegirà el salt de línia.

Per exemple:

print("Hola ", end="")
print("món!")
Hola món!

Corregeix aquest programa perquè tot el càlcul, inclòs el resultat, s’imprimeixi en una sola línia. No canviïs el nombre de comandaments print utilitzats.

print(5)
print(" + ")
print(8)
print(" - ")
print(4)
print(" = ")
print(5 + 8 - 4)

Conceptes clau

  • Variable: espai on es desa informació per utilitzar-la més endavant.
  • Tipus de dades: defineix el tipus d’informació (cadena, enter, decimal...).
  • Enter: nombre sense part decimal.
  • Float: nombre amb part decimal.
  • Concatenació: unir dues o més cadenes de text.
  • f-string: cadena de text especial que permet incrustar variables dins del text.
  • str(): converteix un valor a cadena de text.
