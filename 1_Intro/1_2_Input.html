Entrada de dades en Python

Objectius d'aprenentatge

  • Aprendre a escriure un programa que utilitzi dades introduïdes per l'usuari.
  • Fer servir variables per emmagatzemar i mostrar aquestes dades.
  • Combinar textos (cadenes de text).

Entrada de dades

L'entrada de dades es refereix a qualsevol informació que un usuari dóna al programa. Específicament, la funció de Python input() llegeix una línia d'entrada introduïda per l'usuari. També pot utilitzar-se per mostrar un missatge a l'usuari per demanar una entrada específica.

El programa següent llegeix el nom de l'usuari amb la funció input(). Després l'imprimeix amb la funció print():

nom = input("Com et dius? ")
print("Hola, " + nom)

L'execució d'aquest programa podria tenir aquest aspecte (l'entrada de l'usuari en vermell):

Com et dius? Pau Python
Hola, Pau Python

El que imprimeix aquest programa depèn parcialment de l'entrada de l'usuari. Això vol dir que l'execució del programa també podria tenir aquest aspecte:

Com et dius? Paula Programadora
Hola, Paula Programadora

La paraula nom en aquest programa és una variable. En el context de la programació, una variable és una ubicació per emmagatzemar algun valor, com una cadena de text o un enter. Aquest valor es pot utilitzar més tard, i també es pot canviar.

Nomenclatura de variables

En principi, les variables es poden anomenar lliurement, dins d'uns límits especificats en el llenguatge Python.

És una pràctica de programació internacional comuna anomenar les variables en anglès, però pots trobar-te amb codi on les variables s'anomenen en altres llengües, com la llengua nativa del programador. El nom de la variable no té cap efecte directe sobre el seu contingut, de manera que el nom, en aquest sentit, no importa. No obstant això, sovint pot ser útil per entendre com funciona el codi si les variables s'anomenen lògicament i de manera consistent.

Referenciació d'una variable

Es pot fer referència a una sola variable moltes vegades en un programa:

nom = input("Com et dius? ")

print("Hola, " + nom + "!")
print(nom + " és un nom força bonic.")

Si l'usuari dóna el nom Pau Python, aquest programa imprimeix el següent:

Com et dius? Pau Python
Hola, Pau Python!
Pau Python és un nom força bonic.

Fem una ullada més de prop a la manera com s'utilitza la funció print() anterior. Dins dels parèntesis de la funció hi ha tant text entre cometes com noms de variables que fan referència a l'entrada de l'usuari. Aquests s'han combinat amb un operador +, que concatena dues cadenes de text en una sola cadena.

Les cadenes de text i les variables es poden combinar força lliurement:

nom = input("Com et dius? ")

print("Hola " + nom + "! Deixa'm assegurar-me: et dius " + nom + "?")

Si l'usuari dóna el nom Elena Exemple això imprimeix:

Com et dius? Elena Exemple
Hola Elena Exemple! Deixa'm assegurar-me: et dius Elena Exemple?

Més d'una entrada

Un programa pot demanar més d'una entrada. Fixa't com a continuació cada funció input() emmagatzema el valor rebut en una variable diferent.

nom = input("Com et dius? ")
correu = input("Quin és el teu adreça electrònica? ")
malnom = input("Quin és el teu malnom? ")

print("Assegurem-nos que ho hem entès bé")
print("El teu nom: " + nom)
print("La teva adreça electrònica: " + correu)
print("El teu malnom: " + malnom)

El programa podria imprimir això, per exemple:

Com et dius? Francesca Fictícia
Quin és el teu adreça electrònica? francesca99@exemple.com
Quin és el teu malnom? Fran
Assegurem-nos que ho hem entès bé
El teu nom: Francesca Fictícia
La teva adreça electrònica: francesca99@exemple.com
El teu malnom: Fran

Si s'utilitza la mateixa variable per emmagatzemar més d'una entrada, cada nou valor reemplaçarà l'anterior. Per exemple:

adreca = input("Quina és la teva adreça? ")
print("Així que vius a l'adreça " + adreca)

adreca = input("Si us plau, escriu una nova adreça: ")
print("La teva adreça ara és " + adreca)

Un exemple d'execució del programa:

Quina és la teva adreça? Carrer Python 101, Pis 3D
Així que vius a l'adreça Carrer Python 101, Pis 3D
Si us plau, escriu una nova adreça: Carrer Nou 999
La teva adreça ara és Carrer Nou 999

Això vol dir que si s'utilitza la mateixa variable per emmagatzemar dues entrades successives, no hi ha manera d'accedir al primer valor d'entrada després que hagi estat reemplaçat pel segon:

adreca = input("Quina és la teva adreça? ")
adreca = input("Si us plau, escriu una nova adreça: ")

print("La teva adreça ara és " + adreca)

Un exemple de com podria ser la sortida del programa:

Quina és la teva adreça? Carrer Python 10
Si us plau, escriu una nova adreça: Passeig del Programador 23
La teva adreça ara és Passeig del Programador 23

Exercici 4: Corregeix el codi: Expressions

Aquí tens un programa que hauria de demanar tres expressions i imprimir-les, així:

La 1a part: Pompeu
La 2a part: Fabra
La 3a part: i Poch
Pompeu Fabra i Poch

No obstant això, hi ha alguna cosa equivocada amb el codi de sota. Si us plau, corregeix-lo.

part = input("La 1a part: ")
part = input("La 1a part: ")
part = input("La 1a part: ")
print(part + part + part)

Exercici 5: Conte

Escriu un programa que imprimeixi el conte següent. L'usuari dóna un nom i un any, que s'han d'inserir a la impressió.

Si us plau, escriu un nom: Jordi
Si us plau, escriu un any: 1572

Jordi és un valent cavaller, nascut l'any 1572. Un matí en Jordi es va despertar amb un soroll terrible: un drac s'apropava al poble. Només en Jordi podia salvar els residents del poble.

El conte ha de canviar segons l'entrada donada per l'usuari.

Conceptes clau

  • Entrada de dades: informació que l'usuari introdueix en un programa mitjançant el teclat.
  • Variable: espai on es guarda un valor (text o nombre) que pot canviar.
  • Cadena de text: conjunt de caràcters entre cometes, utilitzat per representar paraules o frases.
  • Funció input(): permet obtenir dades escrites per l'usuari.
  • Funció print(): mostra informació o resultats per pantalla.
  • Concatenació: acció d'unir diverses cadenes de text o variables en una sola.
