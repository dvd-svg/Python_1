Entrada de dades en Python

Objectius d’aprenentatge

  • Aprendre a escriure un programa que utilitzi dades introduïdes per l’usuari.
  • Fer servir variables per emmagatzemar i mostrar aquestes dades.
  • Combinar textos (cadenes de caràcters).

El terme entrada fa referència a qualsevol informació que l’usuari proporciona al programa. En Python, la comanda input llegeix una línia de text introduïda per l’usuari. També pot mostrar un missatge per demanar una entrada concreta.

nom = input("Com et dius? ")
print("Hola, " + nom)

Exemple d’execució:

Com et dius? Pau Python
Hola, Pau Python

Variables

La paraula nom és una variable. En programació, una variable és un espai on es guarda un valor (un text o un número). Aquest valor pot utilitzar-se o canviar-se més endavant.

Nom de les variables

Els noms de les variables poden escollir-se amb bastanta llibertat, seguint certes normes de Python. El més important és que siguin lògics i descriptius.

Exercici: Nom dues vegades

Escriu un programa que demani el nom de l’usuari i el mostri dues vegades, una sota l’altra.

Com et dius? Pau
Pau
Pau

Referència a una variable

Una variable pot utilitzar-se diverses vegades dins del programa:

nom = input("Com et dius? ")
print("Hola, " + nom + "!")
print(nom + " és un nom molt bonic.")

Si l’usuari escriu Pau Python:

Com et dius? Pau Python
Hola, Pau Python!
Pau Python és un nom molt bonic.

Combinació de cadenes i variables

nom = input("Com et dius? ")
print("Hola " + nom + "! El teu nom és " + nom + ", oi?")

Exemple:

Com et dius? Elena Exemple
Hola Elena Exemple! El teu nom és Elena Exemple, oi?

Exercici: Nom i signes d’exclamació

Demana el nom i mostra’l dues vegades en una mateixa línia, envoltat de signes d’exclamació:

Com et dius? Pau
!Pau!Pau!

Més d’una entrada

Un programa pot demanar més d’una dada a l’usuari:

nom = input("Com et dius? ")
correu = input("Quina és la teva adreça de correu? ")
sobrenom = input("Tens algun sobrenom? ")

print("Revisem que sigui correcte:")
print("Nom: " + nom)
print("Correu: " + correu)
print("Sobrenom: " + sobrenom)

Exercici: Història

Demana un nom i un any, i crea una història personalitzada com aquesta:

Introdueix un nom: Maria
Introdueix un any: 1572

Maria és una valenta cavallera nascuda l’any 1572. Un matí, Maria es va despertar amb un gran terrabastall: un drac s’acostava al poble. Només Maria podia salvar-ne els habitants.

Conceptes clau

  • Entrada de dades: informació que l’usuari introdueix en un programa mitjançant el teclat.
  • Variable: espai on es guarda un valor (text o número) que pot canviar.
  • Cadena de text: conjunt de caràcters entre cometes, utilitzat per representar paraules o frases.
  • Funció input(): permet obtenir dades escrites per l’usuari.
  • Funció print(): mostra informació o resultats per pantalla.
  • Concatenació: acció d’unir diverses cadenes de text o variables en una sola.
