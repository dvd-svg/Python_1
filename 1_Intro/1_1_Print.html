Introducció a la programació: Hola món

Objectius d'aprenentatge

  • Aprendre a escriure i executar el teu primer programa en Python.
  • Fer servir la instrucció print() per mostrar sortida per pantalla.
  • Utilitzar la programació per fer operacions aritmètiques senzilles.

Un programa informàtic està format per una sèrie de comandaments; cada comandament indica a l'ordinador que faci una acció. Aquests comandaments s'executen un darrere l'altre. Poden servir per fer càlculs, comparar valors, canviar el comportament del programa, mostrar missatges o demanar entrada de dades a l'usuari.

Comencem familiaritzant-nos amb la funció print(), que s'utilitza per mostrar text a la pantalla. En aquest context, "imprimir" vol dir que el programa mostrarà un text o resultat per pantalla.

Imprimir text

El programa següent mostrarà la línia "Hola món!" per pantalla:

print("Hola món!")
Hola món!

Si vols imprimir text, cal que el text estigui entre " o '. Si no hi poses cometes, Python intentarà interpretar el contingut com a codi i es produirà un error.

Per exemple, si escrivim això sense cometes:

print(Hola!)

Python donarà un missatge d'error com aquest:

File "", line 1
  print(Hola!)
              ^
SyntaxError: invalid syntax

En resum, per imprimir text cal utilitzar cometes perquè Python reconegui una cadena de text.

Aquest programa imprimeix tres línies de text a la pantalla.

Operacions aritmètiques amb print()

També pots posar operacions aritmètiques dins d'un print(). Python calcula el resultat i el mostra. Observa que les operacions no van entre cometes:

print(2 + 5)
print(3 * 3)
print(2 + 2 * 10)
7
9
22

Si poses la mateixa expressió entre cometes, Python la tractarà com una cadena de text i imprimirà l'expressió tal qual:

print(2 + 2 * 10)
print("2 + 2 * 10")
22
2 + 2 * 10

Recorda: sense cometes és un càlcul (números), amb cometes és una cadena de text (text literal).

Exercici 4: Minuts en un any

Comentaris en el codi

Qualsevol línia que comenci amb el símbol # és un comentari. Els comentaris són notes per explicar el codi, que Python ignora durant l'execució.

print("Hores en un any:")
# hi ha 365 dies en un any i 24 hores en cada dia
print(365*24)
Hores en un any:
8760

També es poden afegir comentaris curts al final d'una línia:

print("Hores en un any:")
print(365*24) # 365 dies, 24 hores cada dia

Fins ara has utilitzat cometes dobles per imprimir cadenes. Python també accepta cometes simples. Escriu un programa que imprimeixi exactament aquest text (incloent cometes i parèntesis):

print("Hola a tothom!")

Conceptes clau

  • Sortida: informació que el programa mostra a la pantalla (normalment amb print()).
  • Funció print(): mostra informació o resultats per pantalla.
  • Cadena de text: seqüència de caràcters tancada entre cometes.
